Your two g++ lines

Practice: slow, loud, catches the off-by-one.

g++ -std=c++17 -Wall -Wextra -Wshadow -Wconversion -g -fsanitize=address,undefined -D_GLIBCXX_DEBUG sol.cpp -o sol

What a judge usually runs.

g++ -std=c++17 -O2 sol.cpp -o sol

Your turn

main.c and square.c disagree about what square is:

// main.c                      // square.c
int square(int);               double square(double x) { return x * x; }

You build with gcc -Wall -Wextra main.c square.c -o app. Who catches the mismatch: the compiler, the linker, or nobody? Answer in the thread before you test it.
